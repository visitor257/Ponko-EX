# log

开发过程中撞上的问题，**流水账**。不是正式文档，不用校对措辞，写得糙没关系 ——
目标是**下次撞上同一面墙时能一眼认出来**，而不是写给人看的文章。

## 格式

一个文件 = 一段时间 / 一件事。文件名 `YYYY-MM-DD-短标题.md`。

每条尽量写清三件事：

```
### 现象
看到什么（报错原文、截图描述、行为）
### 原因
查出来是什么
### 做法
怎么改的 / 绕过去了 / 为什么不能那么改
```

**现象优先写原始报错**。三个月后搜关键词靠的是那串英文，不是我的转述。

## 一句话版（最容易忘的）

- 中文路径 → AGP 拒绝构建；`.bat` 必须纯 ASCII，`.ps1` 必须 UTF-8 **带 BOM**
- **新装的插件一定连不上**（stopped），必须靠它自己的 Activity 启动一次
- 插件必须和宿主**同密钥签名**，否则 `SecurityException`
- AIDL 改了 → **重发 SDK AAR + 重编插件**，只重编宿主没用
- 判包看 **sha256**，相邻版本字节数可能完全相同
- 走 API 推仓库时，`git ls-tree` 要加 `-z`（否则中文路径被转义成假路径）
- 推完用 **tree sha** 对账：`git rev-parse <br>^{tree}` == 远端 `tree.sha`
- **接口写完不等于功能可用** —— `stopSpeaking()` 摆了很久没人调；
  参数在 `SynthesisRequest` 里躺了很久没人填。改完要问"哪个 UI 会触发它"
- 接回调前先看**中间层怎么转发**：`PluginSession` 把 `CANCELLED` 从 error 改成了 stage
- `wakeLock.acquire(t)` 是一次性的，到点就掉；长任务必须续期
- **别用下游性能约束限制上游输入**：40 字上限是按某个模型的 RTF 算的，
  却成了所有插件的界面规则。该做的是把耗时摆给用户看，不是替他决定
- **默认值按最坏情况定**：默认"连上就加载引擎"，对轻插件只是省一次点击，
  对重插件就是没请求过就占几个 G。代价不对称时，往便宜的那边倒
- **worktree 里的改动先 commit 再 `remove`**，`--force` 会连未提交的一起丢
- **重插件才测得出时序与资源问题**：Echo 的卸载瞬间完成，"卸载慢/无回调/窗口内合成"
  三条全都不会发生。轻插件验链路，重插件验边界
- **Kotlin 块注释可嵌套**：注释正文里写 `/` + `*`（比如举例 MIME 的 `audio/*`）
  会再开一层注释，把后面代码全吞掉。报错却是"Unclosed comment"指向文件末尾
- **别给 `@Parcelize` 类加字段**：老插件写出的 Parcel 少一个字段，宿主读到边界外直接抛。
  改 AIDL 末尾加方法 —— 版本号能挡住，Parcel 顺序挡不住
- **SDK 里不要放宿主界面文案**：SDK 会打进每个插件 APK，等于让插件揣一份别的 App 的字
- **一个按钮需要"第二次点它时改名"，说明两个动作被绑成了一个** —— 拆开，别改名
- 按钮改名后，**提示文字里引用按钮名的地方**要跟着走，否则同屏两个说法
