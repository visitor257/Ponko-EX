# 启动时弹两个提示、卡片加「关于」

两件事，一件是删噪音，一件是加信息入口。

---

## 一、启动时弹两个提示

### 现象

宿主每次冷启动，只要装了 Ponko-EX 的插件，就会弹一两个 toast，
内容是连接失败的结论（`bindService` 返回 false 之类）。

### 原因

`onPluginStateChanged` 里，状态变成 `FAILED` 就 toast 一句：

```kotlin
if (state == PluginConnection.State.FAILED && detail != null) {
    val head = detail.lineSequence().firstOrNull() ?: detail
    if (head != lastToasted) { lastToasted = head; toast(head) }
}
```

而宿主启动时会**自动重连所有已启用插件**。插件只要处于 stopped 状态
（装完没激活过、或被系统清掉），每次重连都必然失败 —— 于是装几个插件弹几个。

我去重了（`lastToasted`），但那只防"同一句话连弹一串"，
**防不住"每次冷启动都弹一次"** —— 那正是用户看到的。

### 做法

删掉这段 toast，失败信息只留在卡片上。

判断依据：**这些弹窗出现的时刻，用户什么都没做。**
弹窗的唯一作用是让人知道"出事了"，但这里"出事"是预期中的常态
（stopped 是 Android 的机制，不是插件写错了）。而真正要排查的人，
卡片上有**完整多行原因**、可长按复制，toast 一秒就没了本来也不够用。

顺带删掉 `lastToasted` 字段 —— 只服务于这个 toast，留着会让下一个人
以为还有 toast 要维护。

### 没有丢信息

卡片上原本就有：

- 状态行（红字，"连接失败"）
- `detail` 全文（多行、`setTextIsSelectable`，可长按复制贴给作者）
- 「插件还没被系统放行，点上面的「激活」即可」这句指引

所以删 toast 是**减噪音，不减信息**。

## 二、卡片加「关于」

### 需求

卡片上「卸载」左边加一个「关于」，点下去弹窗显示**插件自己写的关于文档**
（纯文本、可复制）。插件没写就显示"无"。

### 位置为什么在「卸载」左边

卸载是这一行里唯一的破坏性按钮，按惯例钉在最右 —— 离拇指最远，
也和其它按钮拉开视觉距离。关于是只读信息入口，放它前面，
不会和卸载挨着误点。

（顺带把注释里"一行排四个"改成五个，并写清"已经接近上限，再造按钮就得换行或收菜单"。）

### 数据从哪来：manifest，不是 AIDL

```xml
<meta-data android:name="ponko.about" android:value="短文本" />
<meta-data android:name="ponko.about" android:resource="@raw/about" />
```

**两个理由，第二个是决定性的：**

1. 关于文档是**静态文本**，跟着 APK 版本走，不需要跨进程协议。
   加 AIDL 方法就得升 SDK、所有插件重编 —— 代价和收益不成比例
   （和 `ponko.actions` 是同一个判断）
2. **插件连不上时也要能看**。卡片最需要"这是什么、谁做的"的时刻，
   恰恰是插件 stopped / 连接失败的时候。走 AIDL 的话那种情况只能显示"无"

### 实现里的两个坑

**① `android:resource` 读到的不是字符串**

用 `android:resource="@raw/about"` 时，meta-data 里的值是一个 **int 资源 id**。
直接 `getString()` 拿到的是 `"2131689472"` 这种十进制字符串，弹窗会显示一串数字。

所以先 `getInt(key, 0)`：非 0 → `createPackageContext(pkg, 0).resources.openRawResource(id)`
读成 UTF-8 文本；0 → 才是走 `getString()` 的内联写法。

**② `setMessage` 的内容复制不了**

`AlertDialog.setMessage` 显示的是不可选中的 `TextView`，长按选不了。
而这个弹窗的内容就是给人复制用的（模型许可、作者联系方式），
所以自己建 `TextView`：`setTextIsSelectable(true)` + 包一层 `ScrollView`（文档可能很长），
再配一个「复制」按钮（只有真有内容时才给 —— 对着"无"提供复制很荒唐）。

### "无"不是错误

没声明 `ponko.about` 就显示"无"，用 `pal.hint` 色（比正文淡），
不弹提示条、不写日志。老插件都没有这个字段，那是正常状态。

---

## 一句话版

- **预期中的常态失败不该弹窗**：stopped 是 Android 机制，不是故障；
  启动时自动重连必然撞上它
- 删弹窗之前先确认**信息还在别处**（卡片有全文 + 可复制），否则就是减功能
- 长文本给用户复制 → 必须 `setTextIsSelectable`，`setMessage` 做不到
- `android:resource` 的 meta-data 值是**资源 id（int）**，不是文本
- 关于/自述这类**静态**信息走 manifest：不用升 SDK，而且**插件连不上时也能看**
